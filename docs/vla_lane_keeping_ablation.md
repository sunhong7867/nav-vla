# VLA 차선 유지 애블레이션 — 어느 층이 무엇을 기여했나 (2026-08-07)

> **스냅샷 주의 (2026-08-24 부기):** 이 문서는 2026-08-07 이전 시점 기준이다. 이후 변경 — v8/v8g 방향·직행 축, "직행은 좌표 내비 위임, v8g는 순항+반응형 전담" 결정(08-24) — 은 [ver/README.md](ver/README.md) 참조.

"학습 없이 감속·조향 규칙을 얹으면 그건 VLA가 조작하는 게 아니지 않나?"라는
질문(사용자, 2026-08-07)에 대한 정직한 분해. 모든 수치는 링 프로브(115 s×2,
안쪽/바깥)를 **기하 기준**(`tools/eval/geometric_lane_check.py`, 기하학적 차선
중앙 대비 |구간 중앙값| > 0.70 m = 차선 밟음)으로 판정한 것.

## 애블레이션 표 (v6-60K)

| 구성 | 성격 | 밟은 구간(안+바깥) | 최대 편차 |
|---|---|---|---|
| replay + fast (기본) | **VLA 단독** | **5+3 = 8곳** | 1.13 / 1.07 |
| replay + normal | VLA 단독 (문장만 변경) | 3+2 = 5곳 | 1.17 / 0.81 |
| preview + fast | VLA + 추종 계층 | 1+1 = 2곳 | 0.77 / 0.99 |
| preview + normal | VLA + 추종 계층 | 1+0 = 1곳 | 0.75 / 0.69 |
| + 감속 a_lat 0.5 | + 속도 규칙 | 0+1 = 1곳 | 0.62 / 0.71 |
| **+ 감속 a_lat 0.8** | + 속도 규칙 | **0곳** | 0.65 / 0.68 |
| **+ 감속 0.6 + 부스트 1.1** | + 속도·조향 규칙 | **0곳 (재현 2/2)** | 0.66 / 0.45 |

참고: v7(DAgger)은 preview+normal에서 1+1곳 — 데모 기준 v6과 동급, 교체 불요.

## 층별 기여 해석

1. **VLA(학습)가 대부분을 한다** — 문장 조건에 따라 차선을 고르고 링을 돌며
   이탈 0. 다만 8개 구간에서 중앙을 0.7~1.1 m 벗어남.
2. **preview 추종 계층이 8곳 → 1곳** — 가장 큰 단일 기여. 이 층은 VLA가
   그린 경로를 그대로 쓰되 실행만 바꾸므로(전방 2~3 m 평균 곡률 추종)
   "VLA의 판단"으로 분류 가능. 실물 VLA 시스템의 표준 구조(모델 위 저수준
   추종기).
3. **손규칙(감속/부스트)은 마지막 1곳(≈1 cm 초과)을 닫는 역할** — 이 부분은
   VLA가 아니라 고전 제어가 맞다. 규칙 없이도(preview+normal) 사실상 달성
   직전이며, 속도 규칙만으로도(0.8) 0곳이 된다.

## 순수성 스펙트럼과 사용 지침

```
순수 VLA ◀──────────────────────────────────────▶ 고전 스택
replay    preview      +감속        +감속+부스트    VLA_AD(조언형)
(8곳)     (1곳)        (0곳)        (0곳, 여유↑)    (0곳, 주행은 YOLO)
```

- **논문 주장용 "순수" 구성**: `preview + normal` — 손규칙 0개, 밟음 1곳
  (그마저 0.75 m, 5 cm 초과). "학습 정책 + 표준 추종기"로 서술 가능
- **손규칙 최소 구성**: `+ curv_slow_alat 0.8` — 조향은 건드리지 않고
  속도만 물리 한계로 캡. 밟음 0곳
- **데모 구성(현행)**: `+ 감속 0.6 + 부스트 1.1` — 마진 최대(0.66/0.45).
  부스트는 정책의 커브 언더스티어 편향(~10%)을 보정하는 규칙임을 공개할 것
- 전환은 파라미터만: `curv_boost:=1.0 curv_slow_alat:=0.0`이면 순수 구성

## 고속 주행 시도 (같은 날 16:xx) — 서빙으로는 불가 확인

"저속에서 안 밟으면 고속도 가능해야 하지 않나"(사용자) 검증: speed_scale 1.25
(≈raw 250 페이스) + 예측 코너 제동(`curv_brake_decel`, 신규 구현) 프로브 결과
**밟음 0→7곳, 평균 속도는 2.3→2.5 m/s로 미미**. 증폭이 정책의 학습된
조향 타이밍을 어긋나게 함(항상 계획보다 앞서 도착). 결론: 고속은 서빙이
아니라 **raw 250 티어 코퍼스 수집+재학습**이 정공법. 예측 제동 코드는
250 티어 학습 후 레이싱 라인용으로 보존.

## 장기 방향

부스트가 메꾸는 "커브에서 10% 덜 꺾는 편향"은 실차 HG-DAgger가 데이터로
흡수해야 할 몫이다. 손규칙은 비계(scaffolding)로 명시하고, 실차 파인튜닝
후 같은 애블레이션을 재실행해 규칙 없이 0곳이 되는지 확인하는 것이 목표.
