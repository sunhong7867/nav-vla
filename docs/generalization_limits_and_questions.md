## 1. 역방향 주행 관찰 — "이러면 VLA라고 할 수 있나?"

**관찰** (2026-08-06, 사용자 실험): 차를 180° 돌려놓으면 정책이 계속 좌회전만
명령해 트랙 밖으로 나감. 시계방향 주행 시연이 코퍼스에 0건이라, 낯선 시각
입력을 가장 비슷한 학습 경험(반시계 = 결국 왼쪽으로 감김)에 패턴매칭한 결과.

**해석**: "오른쪽으로 돌면 된다"는 목표 역산 추론 회로가 현세대 VLA에는 없다.
VLA의 V-L(사전학습 이해)은 진짜지만 **A는 시연 분포 안에서만 산다** —
RT-2/π0에도 정도만 다를 뿐 존재하는 모방학습 공통 한계.

**대응 옵션**: ① 과제를 "지정 방향 링 주행"으로 스코프 정의 (실도로도 일방통행;
채택), ② 미러 증강(이미지 좌우반전 + 조향 부호 반전 + 좌/우 어휘 스왑)으로
재수집 없이 시계방향 데이터 생성 — 하룻밤 실험 후보로 보류.

## 2. 월드모델과의 관계 — "모르는 상황에 알아서 대처하나?"

안 한다. 현 VLA는 **반응형 정책**(관측→행동 패턴매칭)이고, "이 행동을 하면
세계가 어떻게 될까"를 시뮬레이션하는 내부 모델(월드모델)이 없다. 대형 랩들이
실제로 범용성을 얻는 수단은 추론이 아니라 **데이터 다양성 물량**이며, 주행
월드모델(GAIA-1/2, DriveDreamer)은 현재 주로 학습용 데이터 생성기 단계.
"모르는 상황 대처"는 분야 전체의 미해결 문제로, 본 과제 스코프 밖.

## 3. 교수님 질문 — "다른 트랙에서도 잘 하겠니?"

**답**: 단일 트랙 코퍼스로는 보장이 없는 정도가 아니라 잘 못 할 가능성이 높다.
차선 추종의 시각 상대적 부분은 일부 전이될 수 있으나, 배경·질감·곡률 분포에
과적합돼 있고, 존 좌표 인프라(zone_map, navigator)는 트랙 전용이라 아예 재등록
필요. 반사실 검증(2.51 m)도 "이 트랙에서의" 언어 접지 증명일 뿐이다.

**계획된 실험 (일반화 지도 완성)**:
1. 교차 트랙 제로샷 — 레이아웃 다른 제2 트랙 월드에서 v7 그대로 평가,
   이탈률·편차 정량화 ("얼마나 못 하는가" 자체가 데이터)
2. 일반화 곡선 — 새 트랙 에피소드 10/30/100개 파인튜닝별 성능 회복 측정
   → "새 환경 적응에 필요한 데이터량"
3. (여유 시) 질감·배경 도메인 랜덤화로 경계 밀기

기존 부정 결과와 묶으면 일관된 스토리가 된다:
**A3(표현 축) + 역방향(방향 축) + 교차 트랙(환경 축) = 이 VLA의 일반화 지도.**

## 4. 청크 커밋의 구조적 긴장 — "그럼 차선 안 밟기 어렵겠는데?"

맞다. 추론 ~1.2 s(RTX 4060) 때문에 3 s 청크 + 2.1 s 커밋으로 운용하며, 커밋
구간은 시각 보정이 없는 개루프다. 측정된 편차 0.26~0.54 m가 커브 전환부에
몰리는 것이 정확히 이 비용이고, 선생(매 프레임 폐루프, 0.16~0.30 m)의 ~2배로
수렴한 것은 구조상 타당한 수준. 좁히는 레버: DAgger(진행 중), 추론 고속화
(양자화/경량화 → 커밋 단축; 단 과거 스윕에서 0.6 s 커밋은 차선 결정 붕괴),
청크 길이 단축 재학습. "선생 수준 정밀도" 자체는 데모 목적상 비목표로 판단.

## 5. 장애물·신호등 — 스코프와 구성안

- VLA(v6/v7)는 장애물·신호등 시연 0건 → 인지도 대응도 불가 (미션 런치로
  바꿔도 능력이 생기지 않음)
- 학습 없이 가능한 것: **governor 안전 레이어** — 브리지 출력을 `/cmd_nav`로
  리매핑하고 obstacle_monitor(gz 실측) + governor가 장애물 시 차단·정지.
  "VLA는 주행 지능, 안전은 규칙 레이어"라는 실차 표준 구도. 단 이는 **정지**만
  제공하며 **회피**(차선 변경 통과)는 별도 시연 수집 + 재학습 필요 (v8 후보)

## 6. 자주 정리한 개념 (발표용 한 줄들)

- E2E vs VLA: E2E는 "신경망 하나로 운전"이라는 구조, VLA는 거기에
  "사전학습 VLM 앞단 + 자연어 조건"을 얹은 계열. 속은 둘 다 모방학습
- 사전학습 VLM = 읽기·보기·말귀 되는 신입사원. 시연 = 실제 업무 교육.
  시범 없는 업무는 말귀를 알아들어도 못 한다 (A3가 그 증명)
- 자연어 = 모델 안 여러 행동 중 하나를 고르는 스위치 + 사람 인터페이스
- 제어값은 한 줄기 — VLM이 "개입"하는 게 아니라 모델 앞단 그 자체.
  텍스트 병목 없이 연속 특징으로 액션 익스퍼트에 전달
- 최종 주장 문구: "시연 분포 안에서 언어 조건 주행이 검증된, 계층 보조
  (파서·좌표 감독·안전 레이어)를 갖춘 소형 VLA"
