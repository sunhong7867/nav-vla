# stage_a vs SmolVLA — 학습 입력·시뮬 출력 파이프라인 비교와 "VLA인가"에 대한 판정

## 1. stage_a 파이프라인 (2026-07 초, v0 베이스라인)

### 학습 입력 → 출력

```
π( 카메라 이미지 128×128,
   goal zone ID        ← zone_map 어휘 사전의 정수 인덱스 (언어 아님)
   task/lane mode ID   ← {default, lane1, lane2, direct} = {0,1,2,3}
   rel_goal (Δx, Δy)   ← 차량 기준 목표 상대좌표, /50 스케일
   상태 5차원 )
 → cmd_vel 1스텝 (선속도 /2.5, 각속도 /1.5 정규화, MSE 회귀)
```

- **학습 방식**: 오라클(지면진실 좌표를 보고 주행하는 기하 제어기) 시연의 행동복제(BC)
- 코드 자신의 주석이 한계를 명시: *"the oracle acted on ground-truth pose, so the
  forward camera only partially observes the state → BC is approximate"* —
  선생의 판단 근거(전역 좌표)를 학생 입력(카메라+상대좌표)이 완전히 담지 못함.
  **rel_goal 좌표 입력이 이 간극을 메워줬고**, 그래서 차선 정밀도가 높았다
- 언어 처리는 모델 밖: Qwen 파서가 문장 → zone ID로 변환해 입력 (계층 분리)

### 시뮬 실행 시

```
카메라 프레임 → action_policy_node → 매 프레임 cmd_vel 1개 → 차량
                     ↑ zone ID·rel_goal은 노드가 좌표계에서 계산해 주입
```

- 매 스텝 반응형. 좌표가 항상 입력되므로 "지금 어디로 가야 하는지"를 모델이
  틀릴 여지가 작음 = 정밀 주행. 대신 **전역 좌표가 없는 환경(실차)에는 이식 불가**

## 2. SmolVLA 파이프라인 (v3y→v7, 현재)

### (a) 수집 — 욜로 시연자, 30 Hz

```
욜로 차선추종 스택이 주행 (navigator가 존 과업 감독)
기록: /camera/image_raw JPEG + 상태[속도, yaw rate, 조향] + 제어 명령
    + 자연어 문장 (에피소드당 1개, counterfactual 그룹 = 같은 출발, 다른 문장)
    + (평가 전용) TF 전역 좌표 — 학습 입력에 넣지 않음
검증: termination(도착/시간창) + off-ring 가드(링 3 m 초과 2초 → 실패)
```

### (b) 변환 — 10 Hz LeRobotDataset

```
observation.images.front  : 프레임 (비디오 인코딩)
observation.state (3)     : [속도 m/s, yaw rate, 조향]
action (3)                : [dx, dy, dyaw]  ← 차량 기준 SE(2) 상대 이동/0.1 s
task                      : 문장 그대로 (토크나이저가 처리)
```

- 크루즈 에피소드는 정지 패딩 금지(종단 속도 < 0.3 m/s일 때만 hold 패딩) —
  "계속 주행" 라벨에 정지가 섞이면 오염

### (c) 학습 — SmolVLA 450M 파인튜닝 (서버 GPU, 60K 스텝 ≈ 8.5 h)

```
SmolVLM2 백본(사전학습, 앞쪽 레이어만 사용)이 이미지+문장+상태를 인코딩
→ 액션 익스퍼트(~100M)가 cross-attention으로 참조하며
  30스텝(3.0초) 액션 청크를 flow matching으로 생성
손실: 노이즈→정답 경로의 속도장 MSE  (batch 8, cosine lr, ~4.6 epoch)
```

### (d) 시뮬 실행 — 폐루프 서빙

```
카메라 → vla_bridge (JPEG q88 + 상태 + 문장, 10 Hz)
      → zmq → vla_policy_server (체크포인트 추론, ~1.2 s/청크)
      → 액션 청크 30×[dx,dy,dyaw] 반환
bridge: v=dx/dt(전진 성분만), w는 곡률 k=w/v 보존해 재계산,
        max_speed 3.2 클램프, speed_slew 0.08(2.4 m/s²) 평활,
        청크 30% 남으면 재추론(≈2.1 s 커밋), 워치독 시 즉시 정지
      → /cmd_vel → 차량
```

- 좌표가 필요한 과업(존 정차)은 모델 밖에서: navigator가 좌표 감독 →
  도착 시 문장 "" + 정지 (GUI가 이 절차를 자동화)

## 3. 한눈 비교

| 단계 | stage_a | SmolVLA |
|---|---|---|
| 시연자 | 기하 오라클 (지면진실 좌표 주행) | 욜로 차선추종 스택 (카메라 주행) |
| 언어 | 모델 밖 (파서→ID) | **모델 입력** (문장 → 토큰, 행동 조건) |
| 좌표 | **모델 입력** (rel_goal) | 모델 입력 아님 (평가·정차 감독 전용) |
| 행동 출력 | cmd_vel 1스텝 (반응형) | 3초 청크 30스텝 (계획형, 2.1 s 커밋) |
| 학습 손실 | MSE 회귀 | flow matching (다중 모드 보존) |
| 백본 | 소형 CNN, from scratch | 사전학습 VLM 450M 파인튜닝 |
| 시뮬 정밀도 | 높음 (좌표 힌트) | 선생 대비 0.26~0.54 m |
| 실차 이식성 | 불가 (전역 좌표 의존) | 구조적 가능 (입력 전부 실차 존재) |

## 4. 다른 자율주행 VLA들의 학습법과 우리 방식의 근거

주행/로봇 VLA의 표준 레시피는 공통적으로 **"사전학습 VLM + (관측, 언어, 행동)
삼중쌍에 대한 모방학습"**이다:

| 모델 | 백본 | 행동 표현 | 학습 |
|---|---|---|---|
| RT-2 (Google) | PaLI류 VLM | 행동을 텍스트 토큰화 | 시연 BC + 웹 코퍼스 공동학습 |
| OpenVLA | Prismatic VLM 7B | 이산 액션 토큰 | Open X-Embodiment 시연 BC |
| π0 (Physical Intelligence) | PaliGemma | **flow matching 연속 청크** | 대규모 시연 BC |
| **SmolVLA (우리 백본)** | SmolVLM2 | **flow matching 연속 청크** | 커뮤니티 시연 BC → 우리가 주행 시연으로 파인튜닝 |
| Waymo EMMA | Gemini | 궤적을 텍스트로 | 주행 로그 파인튜닝 |
| Wayve LINGO-2 | 자체 VLM | 주행 행동 + 언어 해설 | 언어 주석 주행 시연 |
| LMDrive | LLaMA류 | 제어 신호 | 내비 문장 조건 CARLA 시연 |

즉 우리 파이프라인(사전학습 SmolVLM2 + flow matching 액션 익스퍼트 + 언어 조건
counterfactual 시연 BC)은 π0/SmolVLA 계열의 **정석 레시피를 축소 재현**한 것이고,
"언어를 행동과 같이 학습"은 이 분야의 정의적 특징이다. 차이는 규모(에피소드 수백 vs
수만~수십만, 임베디먼트 1개 vs 다수)뿐이다.

## 5. "VLM에 그치는가, VLA인가" — 판정

**VLM**: 이미지+언어 → **텍스트** 출력. **VLA**: 이미지+언어 → **행동** 출력.

우리 시스템이 VLA인 근거 (전부 측정으로 확인):

1. **출력이 행동이다** — 텍스트가 아니라 30스텝 연속 제어 청크. 폐루프에서
   115초×8회 이탈 0으로 실주행 (2026-08-06)
2. **언어가 행동을 인과적으로 바꾼다** — 같은 출발점에서 문장만 바꾸면:
   차선 분리 **2.51 m** (같은 문장이면 0.05 m = 노이즈 바닥), 속도 티어 분화,
   차선 반사실 27×바닥 (2026-08-03~05). "언어를 무시하는 정책"이면 불가능한 수치
3. **시각이 판단 근거다** — 좌표 입력 없이 카메라만으로 차선 유지·복귀
   (시작 지터 ±0.6 m에서 복귀 시연을 학습해 재현)

동시에, 완전하지 않은 지점 (주장 범위의 경계):

- **미학습 표현 미전이** (A3: 헬드아웃 문장 분리 +0.36 m) → 자유 문장은 Qwen
  파서가 정규 문장으로 변환하는 하이브리드로 보완. 대형 VLA들이 어휘 다양성
  물량으로 얻는 것을 우리는 파서로 대체한 것
- **시연 분포 밖 무능** — 역방향 주행, 장애물, 신호등은 시연이 없어 불가.
  이는 RT-2·π0에도 정도만 다를 뿐 존재하는 모방학습의 공통 한계
- **전역 위치 과업은 모델 밖** — 존 정차는 navigator 좌표 감독 (시각만으로
  전역 위치 추정은 이 트랙의 시각적 반복성 때문에 원리적으로 불량)

**판정: VLM이 아니라 VLA가 맞다.** 언어·시각이 행동으로 접지되는 것을
반사실 실험으로 입증했기 때문이다. 다만 정확한 주장은
"**시연 분포 안에서 언어 조건 주행이 검증된, 계층 보조(파서·좌표 감독)를 갖춘
소형 VLA**"이며, 이 경계 설정 자체가 A3·역방향 실험이라는 부정 결과에 근거한다.
