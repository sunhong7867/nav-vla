## 1. v21b 평가 결과

### 1.1 링 주행 — 폐루프 첫 성공

링 위 시작점에서 "Take the outer lane and stop at checkpoint T2, slowly.":

```
30초에 20.3~20.5 m 주행 (0.68 m/s ≈ "slowly" 명령대로)
트랙을 따라 이탈 없이 추종
차선 반사실 (outer vs inner): D_shape 0.894 m = 바닥(0.285)의 3.1×, 공유 10.8 m
```

**같은 모델이 주차 문장과 링 주행 문장을 모두 알아듣는 방향이 열렸다.**
차선 반응 3.1×는 실재하지만 약하다 (오라클 차선 분리는 3.16 m).
underrun 1.39%로 유효성 기준(<1%)을 살짝 넘긴 것은 각주로 남긴다.

### 1.2 주차 — v2b 대비 퇴보

| | v2b (주차만) | v21b (혼합) |
|---|---|---|
| 혼동행렬 | **8/8 대각선** | bay3만 2/2, 나머지 혼동 |
| 정지 | 0/8 (크리프) | 0/8 |

원인은 산수다. 같은 40K 스텝에서:

```
v2b:  주차 노출 = 3.0 에포크 × 100% = 3.0
v21b: 주차 노출 = 2.0 에포크 × 65%  ≈ 1.3     ← 절반 이하
```

v2b의 5K→40K open-loop 추세에서 봤듯 조건화는 에포크에 따라 자란다. 링을 배우느라
주차가 덜 익은 것이지, 링 데이터가 주차를 **방해**한다는 증거는 없다.

## 2. 결정 — 데모는 v2b, v21b는 +40K 연장

- 노트북 데모 스택을 **v2b로 회귀** (주차 8/8이 오늘의 최강 결과)
- v21b를 3090에서 `--resume --steps=80000`으로 연장. 주차 노출이 ~2.5 에포크가 되어
  v2b 수준 회복을 기대. 완료 ~02:30
- 판정: 80K에서 주차 대각선이 돌아오면 **v21b-80K가 통합 데모 모델**, 아니면 데이터
  재배합(주차 oversample) 후 재학습
