## 2. 추가된 것

| 파일 | 역할 |
|---|---|
| `src/nav_vla_pkg/nav_vla_pkg/episode_recorder_node.py` | 레코더 v2 (신규 노드) |
| `src/nav_vla_pkg/scripts/resample_episodes.py` | 오프라인 조인 + **수용 게이트** |
| `gz_pose.py` | `WorldPoseStream.seq` 카운터 추가 |

`data_engine_node.py`는 **건드리지 않았다** — 619 에피소드를 만든 참조 구현이자 어블레이션 기준선이다.

### 2.1 구 레코더의 네 가지 결함과 대응

| 구 레코더 | 결과 | v2 |
|---|---|---|
| 이미지 콜백 안에서 `time.monotonic()` 레이트 게이팅 | 목표 5 Hz → **실측 4.33 Hz, +15.4% 계통오차**, 타임스탬프 없어 복구 불가 | **레이트 제한 없음.** 소스 레이트 그대로 기록, 오프라인에서 정확한 격자로 리샘플 |
| image·pose·cmd를 타임스탬프 없이 한 순간에 융합 | 어긋나면 복구 불가 | **4개 독립 스트림 + 각자 타임스탬프** → 오프라인 조인 |
| 콜백 안에서 `cv2.imwrite` | 디스크 I/O가 콜백을 막음 (레이트 표류의 원인이기도) | 콜백은 큐에 넣기만, **writer 스레드**가 인코딩·기록 |
| `round(..., 4)` | 양자화 이전 신호 파괴 | float64 전량. control은 **3계층 전부** 보존 |

### 2.2 온디스크 스키마

```
data_v2/<session>/ep_XXXX/
    meta.json        schema_version=2, instruction, intent_id, intent_slots,
                     termination(6종), cf_group_id, cf_variant_id,
                     start_pose_key, seed, git_sha, dropped_frames, valid
    frames/          000000.jpg …   소스 레이트(~30 Hz), 데시메이션 없음
    frames.jsonl     {t, seq, file, enc, w, h}          ← t = 이미지 header.stamp
    poses.jsonl      {t, seq, x, y, yaw}                ← 새 샘플일 때만
    control.jsonl    {t, v_cmd, yaw_rate_cmd,
                      oracle_curvature/oracle_v/oracle_steer_rad,   ← 1계층
                      steer_float,                                   ← 2계층
                      steer_cmd,                                     ← 3계층
                      source, override, oracle_age_s}
    events.jsonl     {t, kind, data}
```

**`termination`은 bool이 아니라 6종**(`success/timeout/collision/off_track/stuck/operator_abort`).
bool이었기 때문에 구 코퍼스가 619/619 성공이 되고 복구 데이터가 0이 됐다.

**`oracle_age_s`** — control 행은 `/cmd_vel` 도착 시 기록하며 최근 `/oracle_action`을 병합한다.
둘이 동시에 온 척하지 않고 **병합 시점의 나이를 남긴다.** 리샘플러가 오래된 병합을 거부할 수 있다.

**`start_pose_key`** — 양자화된 pose 해시(5 cm × 2°). 반사실 변형을 묶는 키이고
**수집 시점에만 만들 수 있다.**

### 2.3 시계 — `use_sim_time:=true` 필수

프레임 타임스탬프는 이미지 `header.stamp`(시뮬 시간)에서 온다. 노드 시계가 벽시계면
**두 스트림이 서로 다른 시간축에 놓여 오프라인 조인이 무의미해진다.** 노드가 이걸 감지하면 경고한다.

> **이것은 stepped world 이관을 요구하지 않는다.** R6 함정(`/clock` 정지 → ROS 타이머 사망)은
> world를 **일시정지할 때만** 발동하는데, 여기서는 아무것도 정지시키지 않는다.
> 리셋 시의 일시정지는 `gz_reset`이 벽시계(`time.monotonic`)로 처리하므로 무관하다.

### 2.4 조용한 실패를 큰 소리로 — 두 지점

**프레임 드롭.** writer가 못 따라가면 큐가 찬다. 조용히 버리지 않고 **세고, 에피소드를
`valid: false`로 표시**한다. 드롭된 프레임 하나가 그 에피소드의 타이밍을 복구 불가로 만든다.

**수용 게이트** (`resample_episodes.py`) — 하나라도 걸리면 에피소드 거부:

| 게이트 | 임계 |
|---|---|
| 소스 프레임 간격 최대 | > 0.20 s |
| 최근접 오차 > 0.05 s 인 격자점 비율 | > 5% |
| pose 보간 구간 최대 | > 0.10 s |
| 최근접 오차 중앙값 | > 0.017 s |

> LeRobot은 `timestamp = frame_index/fps`로 **스스로 지어내고 자기 것과 대조**하므로,
> 타이밍이 틀렸다는 걸 하류에서 알려줄 곳이 여기밖에 없다.

### 2.5 행동 표현

```
action = [dx, dy, dyaw]   ego frame @ k, float64 보간된 GT pose에서 유한차분
state  = [speed_mps, yaw_rate_radps, steer_angle_rad]
```

**`cmd_vel`에서 계산하지 않는다** — 그건 값이 9개뿐인 양자화 심볼 테이블이다.
`state`에 goal 정보를 절대 넣지 않는다(계획 §5.4). 넣는 순간 언어 우회로가 생기고
0.0049 rad/s 실패를 재건하게 된다.

### 4.2 리샘플러만 단독 검증 (시뮬 불필요, 30초)

합성 에피소드를 만들어 정답과 대조한다.

```bash
cd ~/ROS2_project/nav-vla
python3 - <<'EOF'
import json, math, os, random, shutil
root='/tmp/synth_session'; shutil.rmtree(root, ignore_errors=True)
def make(name, v, w, dur=8.0, gap_at=None):
    d=os.path.join(root,name); os.makedirs(os.path.join(d,'frames'),exist_ok=True)
    rng=random.Random(1); fr=[];po=[];ct=[]
    gt=lambda t:(v*t,0.,0.) if abs(w)<1e-9 else (v/w*math.sin(w*t), v/w*(1-math.cos(w*t)), w*t)
    t=0.;s=0
    while t<dur:
        if gap_at and abs(t-gap_at)<0.5: t+=0.5; continue
        fr.append({"t":t+rng.uniform(-.004,.004),"seq":s,"file":f"frames/{s:06d}.jpg","enc":"jpg","w":640,"h":480})
        open(os.path.join(d,'frames',f'{s:06d}.jpg'),'wb').close(); s+=1; t+=1/30
    t=0.;s=0
    while t<dur:
        x,y,yaw=gt(t); po.append({"t":t,"seq":s,"x":x,"y":y,"yaw":math.atan2(math.sin(yaw),math.cos(yaw))}); s+=1; t+=1/60
    t=0.
    while t<dur:
        ct.append({"t":t,"v_cmd":v,"yaw_rate_cmd":w,"oracle_curvature":w/max(v,1e-9),
                   "oracle_v":v,"oracle_steer_rad":math.atan(2.86*w/max(v,1e-9)),
                   "steer_float":7*w/0.46,"steering_cmd_int":round(7*w/0.46),
                   "source":"route_oracle","override":"none","oracle_age_s":0.}); t+=1/20
    for fn,rows in (('frames.jsonl',fr),('poses.jsonl',po),('control.jsonl',ct),
                    ('events.jsonl',[{"t":0.3,"kind":"settled","data":None}])):
        open(os.path.join(d,fn),'w').write("".join(json.dumps(r)+"\n" for r in rows))
    json.dump({"schema_version":2,"instruction":"take the first opening","termination":"success",
               "valid":True,"start_pose":[0,0,0],"n_frames":len(fr)},
              open(os.path.join(d,'meta.json'),'w'))
make('ep_0000',1.2,0.15); make('ep_0001',1.8,-0.35); make('ep_0002',0.7,0.0)
make('ep_0003',1.2,0.15,gap_at=4.0)
print("made", root)
EOF

python3 src/nav_vla_pkg/scripts/resample_episodes.py --session /tmp/synth_session --verbose
```
**기대**: `accepted : 3 / 4`, `ep_0003`만 `source frame gap 1.032s > 0.2s`로 거부,
`nearest-error (median) : 2.5 ms`.

속도·각속도가 정답과 맞는지:

```bash
for ep,vt,wt in [('ep_0000',1.2,0.15),('ep_0001',1.8,-0.35),('ep_0002',0.7,0.0)]:
    r=[json.loads(l) for l in open(f'/tmp/synth_session/{ep}/resampled_10hz.jsonl')]
    st=[x['state'] for x in r if x['action']]
    print(f'{ep}: v={statistics.fmean(s[0] for s in st):.4f} (true {vt})  '
          f'w={statistics.fmean(s[1] for s in st):+.4f} (true {wt:+.2f})')
"
```

## 6. 미해결 / 주의

1. **`/oracle_action`이 아직 없다.** 오라클을 만들기 전까지 `control.jsonl`의 1·2계층
   (`oracle_*`, `steer_float`)은 `null`이다. `v_cmd`/`yaw_rate_cmd`는 정상 기록된다.
2. **G1의 1/20 실패 원인 미확인.** 570 에피소드면 ~28회다. 수집 드라이버에서 실패 사유를
   `events.jsonl`에 남기도록 할 것.
3. **디스크.** 30 Hz 원본은 v2 기준 ~11 GB, v3 ~37 GB. `data_v2/`를 `.gitignore`에 추가해야 한다
   (다음 커밋에서 처리).
4. **`use_sim_time` 미설정 시 경고만 하고 기록은 계속한다.** 막을지 여부는 실기동 후 결정.
