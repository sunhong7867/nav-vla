## preview 모드 (vla_bridge_node `track_mode:=preview`)

매 틱, 남은 청크(ego 델타)를 경로로 보고 전방주시 거리(1.2+0.5v, 최대 3 m)
구간의 **평균 곡률** k = Σdyaw/Σds 를 명령. 코너 한복판에선 경로 곡률을
정확히 재현(체계 편향 없음)하고, 창이 코너 끝에 걸릴 때만 직선이 섞여
조향이 미리 풀린다 — 사용자가 관찰한 "코너 탈출 후 조향 늦게 풀림"의 표적 처방.

## 결과 (링 프로브, v6-60K fast)

| | base r1/r2 | preview r1/r2 |
|---|---|---|
| 안쪽 중앙값 | 0.27 / 0.38 | 0.34 / 0.37 |
| **바깥 중앙값** | 0.48 / 0.44 | **0.30 / 0.26** |
| **안쪽 최대** | 1.21 / 1.27 | **0.79 / 0.93** |
| 0.5 초과 구간(합) | 16 / 19 | **8 / 10** |
| T2 코너 탈출 | +0.73/+0.82 | **+0.44/+0.48** |
| Slot4 바깥 | −1.04 | **−0.57** |
| 이탈 | 0/4 | 0/4 |

두 런 모두 같은 방향 — 런 간 분산(±0.1~0.2)을 넘는 일관 개선.
안쪽 중앙값 +0.07은 분산 안. **최대 편차(=차선 초과가 보이는 지표)가
1.2~1.3 → 0.8~0.9로 내려온 것**이 데모 체감 핵심.
