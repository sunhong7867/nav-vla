# 2026-08-06 10:45 — DAgger 사이클 1 착수: 정책의 오차 상태에서 선생 복귀 수집 → v7

[01:40 v6 평가](20260806_0140_v6-eval-demo-final.md)에서 확인한 잔여 문제
(특정 구간에서 차선 중앙을 벗어나 바깥/안쪽으로 치우침, 사용자도 실주행에서 관찰)에
대한 표적 대응. "같은 분포 데이터를 더" 는 v6에서 기각됐으므로, 분포 자체를
**정책이 실제로 방문하는 상태**로 옮긴다 (DAgger, Ross et al. 2011).

## 원리 (요약)

행동복제는 선생이 가는 상태만 배운다 → 정책이 조금 어긋나면 학습 분포 밖 →
오차 복리 누적. DAgger는 **학생이 주행하며 실제로 방문한 상태**에 선생을 놓고
정답(복귀 조향)을 수집해 코퍼스에 합친다. 오차 누적이 T²에서 T로 줄어드는
것이 원 논문의 보장. 우리는 선생이 자동(욜로 스택)이라 사람 개입 없이 돈다.

## 구현

1. **오차 상태 추출** (`dagger_poses.py`): v6 프로브 8회 주행 궤적에서
   선생 라인 대비 0.25~2.0 m 이탈 + 주행 중(v>0.8) 상태 **5,405개** 검출 →
   |편차| 내림차순, 같은 차선 3.5 m 간격, 차선 균형(22+22)으로 **44개 선별**.
   최악 지점: 하단 직선 lane1 +1.84 m, 우측 lane2 −1.70 m, S-커브 등 —
   사용자가 관찰한 치우침 지점들과 일치
2. **수집기 확장** (`collect_corpus.py --start-poses-file`): 지터 대신
   추출 포즈(위치+진행방향)에 정확히 배치, 문장 차선 = 정책이 당시 따르던 차선,
   속도 티어 순환, off-ring 가드 유지
3. **파이프라인** (`y7d_run.sh`): 수집 44 eps(~30분) → resample → package →
   ship(파일수 대조 후 로컬 삭제) → 서버 packed_v7 = packed_v6 + y7d →
   `lerobot/v7` 변환 → `navvla_smolvla_v7` 60K 학습 (완료 ~20시)
