# docs/ver — 변경 이력

코드를 수정할 때마다 이 폴더에 변경 문서를 하나 추가한다.

## 파일명 규칙

```
YYYYMMDD_HHMM_짧은-제목.md
```

예: `20260727_2303_track-localizer-pkg.md`

## 문서에 반드시 넣을 것

| 항목 | 이유 |
|---|---|
| **무엇을 왜 바꿨는지** | 3개월 뒤의 자신이 읽는다 |
| **측정한 수치** | 주장이 아니라 근거. "잘 된다"가 아니라 "RMS 2.8°" |
| **실패하거나 미달한 것** | 성공만 적으면 이력이 아니라 홍보물이 된다 |
| **재현 명령어** | 그대로 붙여넣어 확인 가능해야 함 |
| **미해결 항목** | 다음 세션의 시작점 |

## 원칙

- **되돌릴 수 없는 결정은 근거를 남긴다.** 파라미터를 고른 이유, 버린 대안, 그 이유.
- **음성 결과도 기록한다.** "이 방법은 이 조건에서 실패했다"가 가장 비싼 정보다.
- 파일은 append-only로 취급한다. 나중에 틀린 게 밝혀지면 지우지 말고 새 문서에서 정정하고
  이전 문서를 링크한다.
