# Reasoning VLA 프로젝트 종합 보고서 (2026-08-31 ~ 09-09)

> 대상: 연구 노트/공유용 요약. 버전 상세는 `reasoning_versions.md`,
> 개별 결정 근거는 `ver/`의 날짜별 노트.

## 1. 출발 질문과 목표

"Qwen이 붙이는 해설은 SmolVLA의 근거가 아니다 — 주행하는 모델 자신이
근거를 말해야 하지 않나?"라는 질문에서 출발했다. 목표는 **단일 SmolVLA가
주행(액션)과 그 근거 설명(언어)을 동시에 출력**하되, 설명이 앵무새가
아니라 **이미지·상태에 접지(grounded)** 되었음을 정량 증명하는 것.

## 2. 방법 요약

- **라벨**: 시뮬 특권 정보(실측 포즈·장애물 좌표·차선 기하)에서 규칙으로
  사실 골격 문장을 합성하고, LLM 패러프레이즈는 사실 보존 검증을 통과한
  것만 채택. LLM은 데이터 준비에만 쓰이고 학습·서빙에는 없음.
- **모델**: pip lerobot의 SmolVLA를 포크 없이 subclass — 잠들어 있던
  `lm_head`(47M)를 해동해 언어 헤드로, 프리픽스 공유 2-패스로
  `flow_matching + λ·CE` co-training. 액션 경로는 바이트 동일 유지.
- **평가 3겹**: 학습 곡선의 액션 무회귀 / heldout 자유생성 사실 채점
  (모순 감지) / 라이브 폐루프. 장애물 접지는 장애물 창(전방 14 m) 집중
  샘플로만 측정(무작위 샘플은 신호 희석).
- **사이클 속도**: 라벨 수정→재학습→평가 1사이클 ≈ 3시간 → 열흘간
  r1~r11.

## 3. 핵심 발견 (시간순)

1. **속도 표기 실험(r1~r4)**: 프레임별 다자리 정수는 500M 헤드에서 숫자
   모드 붕괴(r2 "110" 남발, r3 "speed 10" 고정). 해법 = **티어만
   인용**(70/110/150) + trend 단어가 프레임 접지 담당. repetition
   penalty는 사실성 전 항목 악화 — greedy 고정.
2. **희소 신호는 자연 빈도로 안 배워진다(r5→r6)**: 장애물 프레임 10%
   빈도에서 차량 언급 7% → **4배 가중 샘플링으로 100%**, 환각 0,
   기존 지표 무붕괴. 이 프로젝트에서 가장 깨끗한 성공.
3. **관찰-후-회피 시연 설계(v9)**: "모델은 앞차가 멈춘 걸 모른다"는
   인식론적 원칙으로 감속→정지 관찰 2.5 s→통과를 시연·라벨화.
   standstill state 채널(r8)로 언어 phase 결속 성공 — 정지 프레임이
   greedy로 "Stopped …, watching whether it moves"를 말함.
4. **언어-액션 비대칭(r8~r11, 최종 발견)**: 같은 데이터에서 언어 헤드는
   정지·관찰·통과를 결속했지만, **flow-matching 액션 익스퍼트는 희소한
   정지 행동을 끝내 획득하지 못했다**. 데이터 정화(모든 시연 정지선
   ≥6 m), 24배 오버샘플, 서빙 셰이핑 배제(replay 대조), seed 8종 스윕
   (전부 전진)까지 배제한 뒤의 결론 — 모델 측 한계.

## 4. 함정 카탈로그 (재발 방지 자산)

수집·서빙 인프라에서 잡은 실제 사고들. 각각 ver 노트에 상세 기록:

- pkill 자기매치(로컬·원격·heredoc 3변종), 단명 publish 유실
- gz create 서비스 wedging(spawn 반복) → 상주 teleport 설계
- 100 Hz 클록의 스탬프 양자화 / 500 Hz의 CPU 역효과 → 헤더 스탬프
- dynamic_pose 인덱스 시프트 → 근접 매칭 / CLI 스트림(ruby) 코어 잠식
- 차체 반장 무시한 중심거리 판정(3중 오판) → body-extent 기준 정착
- arc 모듈로 랩으로 가드 실명 → signed 거리
- 학습 정규화 오버라이드의 체크포인트 미저장 → live preproc 저장
- 시연 품질 감사 없는 부스트 = 나쁜 시연 증폭 → 스테이징 동적 감사

## 5. 현재 자산

- **모델**: `runs/navvla_reasoning_r11`(클린 데이터, 4ch state) —
  주행 + 장애물 인지 발화. 서빙 `--reasoning-every N` +
  브리지 `/vla/reasoning`(+`standstill_state:=true, cap 3.5`).
- **데이터**: v9r4c(258ep, 전 v1 시연 정지선 검증 통과), heldout 3종.
- **도구**: 라벨러/패러프레이저/검수 리포트, obstacle-window 평가기,
  counterfactual 프로브(텍스트 발산), 수집 파이프라인(가드+동적 감사).
- **문서**: 버전 대장(`reasoning_versions.md`), ver 노트 6편, 본 보고서.

## 6. 방향 옵션과 권고

| | 내용 | 비용 | 리스크 |
|---|---|---|---|
| A | 정지 시연 10배 증량(200+ep) 후 재학습 | 수집 4h+ + 학습 | 이 머신의 수집 수율(≈50%)·불확실한 스케일 응답 |
| B | **데모 실용해**: 감독(chat_gui)이 정지·GO 외부화, r11이 내레이션 | 반나절 | 낮음(기존 회피 감독 재사용) |
| C | **논문화**: r1~r11 감사 트레일 정리 | 집필 | 낮음(재료 완비) |

**권고: B → C 순서.**
- B가 먼저인 이유: 프로젝트의 기존 철학(`code_vs_vla_responsibilities` —
  이산 안전 결정은 코드, 연속 제어와 말은 VLA)과 정확히 일치하고, 이미
  검증된 회피 감독을 재사용하므로 반나절 안에 **완전한 데모**(정지→관찰
  발화→통과, 내레이션은 단일 SmolVLA)가 나온다.
- C가 다음인 이유: 작동하는 데모가 논문의 중심 그림이 되고, §3-4의
  발견(접지 7→100%, 언어-액션 비대칭, 감사 방법론)이 정직한 분석
  섹션이 된다. A는 C의 리뷰가 요구할 때 후속 실험으로 미루는 것이
  비용 대비 합리적.
