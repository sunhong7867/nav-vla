# 시뮬-실차 스케일 교정 노트 (2026-08-07)

사용자 실관찰: 실트랙·유아용 차량 대비 시뮬 차량이 크다.
1차선 장애물 배치 박스(실차 1대 크기 마킹)를 시뮬 프리우스가 세로로 ~1.5배 초과.

## 실측 (시뮬)

| 항목 | 값 |
|---|---|
| 차량 폭 (프리우스) | 1.75 m |
| 차량 전장 | ~4.6 m (휠베이스 2.86) |
| 차선 중심 간격 (lane1↔lane2) | 3.16 m |
| 차선폭 | ~3.16 m |
| 폭 점유율 | **55%** |
| 선 밟는 중심 편차 (margin) | **±0.70 m** |

## 미실측 (사용자 제공 대기)

- 유아용 차량 폭 / 전장
- 실트랙 차선폭
→ 실제 폭 점유율 추정 ~45~50% (시뮬이 더 빡빡 = 보수적 조건)

## 결정

1. **차선주행 라인에서는 차량 크기 유지** — 축소 시 카메라 시점 변화로
   코퍼스·모델 전면 재작업. 폭 여유는 시뮬이 더 어려운 조건이라 유지 무손해
   ("시뮬 통과 → 실차 여유" 논리로 활용).
2. **교정 타이밍 = 장애물 시나리오 착수 시점.** 장애물 코퍼스는 어차피 신규
   수집이므로 그때 실비율 차량(폭 점유 ~45%, 박스에 맞는 전장)으로 교체하고
   그 스케일로 수집. 휠베이스 상수(vla_bridge_node / ackermann adapter의
   2.86)도 동시 갱신.
3. 평가 지표: 기존 0.5 m 임계와 함께 **물리 임계 0.70 m**(시뮬에서 실제로
   차선을 밟는 편차)를 병기.
