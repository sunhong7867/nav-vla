## 1) 회색 화면 — GUI 렌더러 ogre1이 aarch64에서 죽음

증상: Gazebo 창은 뜨는데 트랙·차량 없이 회색. 진단 절차가 결론을 갈랐다:

- **카메라 프레임 캡처로 서버측 무혐의 입증** — `/camera/image_raw`에서
  한 장 떠 보니 트랙·차선·T1 라벨·보닛까지 완벽 (서버 렌더링은 ogre2)
- 범인: 런치의 GUI 전용 인자 `--render-engine-gui ogre`(ogre1) —
  Thor(aarch64)에서 장면이 회색으로 죽는다. **ogre2로 바꾸니 즉시 정상**

수정: `driving_sim.launch.py`가 aarch64면 ogre2, x86이면 기존 ogre 유지
(`NAVVLA_GUI_RENDER_ENGINE` env로 강제 가능). 노트북 거동 무변경.
